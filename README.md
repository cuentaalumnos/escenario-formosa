# Expedición por Formosa · Escenario Multiagente

Elenco: Cacique Taigoyé, Comandante Fontana, Guazuncho y Qomllagay (personajes hechos con IA, con fines educativos).

## Lugares
Arriba a la derecha hay un selector de lugar: **Vuelta Fermoza (río Paraguay)**, **El Colorado · orilla del Bermejo** y **Bañado La Estrella**. Se puede abrir uno directo con `?lugar=vuelta`, `?lugar=colorado` o `?lugar=estrella`. En modo cine el selector se oculta.

## Publicar
GitHub: repositorio público → Add file → Upload files con `index.html` → Settings → Pages → Branch: main. O arrastrar la carpeta a app.netlify.com/drop.

## Importante
- La charla en vivo y las voces de ElevenLabs solo andan con la página publicada (https).
- Cada agente necesita tu dominio en la lista de permitidos y la autenticación desactivada.
- Cada turno gasta créditos de ElevenLabs. La clave de API no se comparte.
